# TravelPal
Travel smart with TravelPal

* TravelPal is a web application that gives users a travel guide to any city in the world
* TravelPal is especially useful for travellers who want to quickly find the top 5 attractions of a city for free, and with a premium subscription discover hidden gems and get an AI-made plan for their days
* To start using TravelPal, user first has to create an account, after that he just searches for a city and gets the guide. With premium he also gets hidden gems and a day-by-day itinerary


# Free and Paid Tier
 
* Free: search any city and get a guide to its top 5 attractions with a short description and a map
* Paid (premium subscription): everything in Free, plus hidden gems, map filters, an AI itinerary builder, saved trips and print-friendly export


# Project Specification

* Backend: Java + Spring Boot
* Frontend: Thymeleaf
* Database: MySQL
* Security: Spring Security
* AI Integration: Google Gemini API
* Maps & Places: OpenStreetMap (Nominatim, Overpass API) + Leaflet
* Communication: REST API (JSON)
* Containers: Docker + Docker Compose
* Version Control: Git + GitHub
